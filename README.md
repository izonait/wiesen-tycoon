# Wiesen-Tycoon

Mäh die Wiese, verkaufe Gras und werde Wiesen-Tycoon.

**Spielen:** https://izonait.github.io/wiesen-tycoon/

Auf dem iPhone in Safari öffnen, auf Teilen tippen und „Zum Home-Bildschirm“ wählen. Dann startet das Spiel wie eine App im Vollbild und läuft nach dem ersten Laden auch offline.

Dieses Repository enthält nur die fertige Web-Version des Spiels.
